## Checklist

Most relied-on first. Counts are references that rely on the item, by role.

1. **Claim: diagrams are drawn ahead of time into SVG files committed to the
   repo, and the browser loads no mermaid code.** Decision. 10 refs: explains 3,
   enforces 3, points 3, repeats 1. E.g. `scripts/render-mermaid.ts:1`,
   `tests/e2e/smoke.spec.ts:143`. The rule applies to every page, Journal pages
   included (`terrarium-overview.md:934`).
2. **Claim: a gate check fails when a committed SVG is missing, empty, has no
   source left, or is unsafe; the fix is to run `pnpm render:mermaid` and commit.**
   Mechanic; home `scripts/verify-mermaid.ts` (in the gate floor,
   `scripts/gate.ts`). 5 refs: enforces 3, explains 1, points 1. E.g.
   `scripts/verify-mermaid.ts:1`, `:56`.
3. **Question: how do diagrams take each Tenant's colours and dark mode without
   JS?** Answer callers expect: the SVG uses `--diagram-*` CSS variables that a
   Tenant maps to its own tokens. Decision, with a mechanic (the token list);
   home `app/utils/mermaid.ts` (`DIAGRAM_TOKENS`). 5 refs: explains 2, enforces 2,
   points 1. E.g. `app/utils/mermaid.ts:15`, `docs/agents/tenant-layers.md:112`.
   **Conflict:** `tenant-layers.md:112` sends readers to ADR-0024 for the
   contract; `app/utils/mermaid.ts:15` and `mermaid-server-side-rendering.md:112`
   say `app/utils/mermaid.ts` is its single home.
4. **Claim: text sizes are measured when the SVG is drawn, so font family and
   size are fixed, not themeable; diagrams use one bundled font (Gelasio) and the
   site ships that font.** Decision; mechanic home `app/utils/mermaid.ts`
   (`MERMAID_RENDER_FONT`) and `app/assets/fonts/`. Label overflow handling lives
   in `scripts/render-mermaid.ts` (`relaxNodeLabelOverflow`). 5 refs: explains 4,
   enforces 1. E.g. `app/components/MermaidDiagram.vue:46`,
   `scripts/render-mermaid.ts:77`.
5. **Question: how is a diagram matched to its SVG file?** A hash of the

   explains 1, enforces 2, points 1. E.g. `scripts/verify-mermaid.ts:1`,
   `tests/unit/mermaid-render.spec.ts:2`.
6. **Claim: only the authoring step runs a browser; CI and production only read
