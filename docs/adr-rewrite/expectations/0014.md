## Flag 2: Conflicts

- **Build time or test time?** `tests/e2e/smoke.spec.ts:4` says the target list is "derived at build time … (ADR-0014)". `tests/support/e2e.ts:59`/`:62` say "derived at **test-time**", single-homed in `shared/expand.ts`, separate from the build-time routing module. The ADR needs to say whether it governs the e2e list at all, or only the shared `expand()` source.
- **Who expands the routes?** `.claude/rules/adr-0002.md:13` says `shared/expand.ts` "expands … routes at build time (ADR-0013, ADR-0014)". `modules/routing.ts:1` and `shared/expand.ts:6` say `modules/routing.ts` derives the map, using `expand()`. This is a minor wording difference, not a real contradiction.
- **Dev-watch:** `content.config.ts:12` expects ADR-0014 to cover the dev-server gap (issue #325). Hist 07-12 records that the ADR once carried a stale "restart needed" caveat, which #370 fixed. A rewrite must not bring that caveat back.

  - 10-02: it referenced code that had been deleted.

  Both show that file names in the ADR go stale.
