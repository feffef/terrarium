## By part of the Platform

**Code and tests.** Need the ADR to state the mechanism (C1: payload, not
client DB), the page cache and its settings (C2), its size bound (C3) and the
`varies` rule for header-reading pages (C5). Tests check navigation without
the client DB (blog, smoke), that a failed payload falls back to the client
DB (C4), locale isolation, and the cache bound. Tenant code relies on two
consequences: "now" staleness bounded by the cache (C7) and payload size
(C8).

**Skills.** No references.

**Agent docs and CLAUDE.md.** No references in `docs/agents/` or CLAUDE.md.
The overview diagram maps `ContentLoadErrorDialog.vue` (C6) and, unclearly,
the container files (C12) to ADR-0028. The research note treats ADR-0028 as
the adopted Avenue 2a, the home for config and byte measurements (C9), the
holder of the cache-bound amendment (C3), and the record of open items (C13).

**Other ADRs and rules.** ADR-0019 (full ADR and rule) needs ADR-0028 to say
navigation mostly skips the client DB, and where it still loads (C1, C4), so
ADR-0019's recovery reach is defined.

**Glossaries.** No references.
