## Checklist (most relied-on first)

1. **Claim: page-to-page navigation inside the app loads a page's data from a
   server-rendered file (`_payload.json`), not from the content database in
   the browser.** Decision. 8 refs: enforces 3, explains 2, points 2, repeats 1.
   nuxt.config.ts:16, layers/blog/tests/e2e/blog.spec.ts:126.
2. **Question: when does the browser content database still load?** Callers
   name: Tinkerfund search, queries re-run after the page mounts, and a failed
   payload fetch (which falls back to the browser database); the error dialog
   therefore shows less often. Decision. 6 refs: enforces 1, explains 2,
   repeats 1, points 2. docs/adr/0019-patched-nuxt-content-client-db-loading.md:199,
   layers/blog/tests/e2e/blog.spec.ts:26.

   enforces 3, repeats 1, points 1. tests/e2e/smoke.spec.ts:60,
   docs/research/content-client-queries-without-wasm.md:376.
4. **Claim: rendered pages are cached on the server; the cache has a size
