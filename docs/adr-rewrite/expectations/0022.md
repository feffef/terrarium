## Checklist (most relied-on first)

1. **Who can let the triage sweep mark issues "ready to build" without asking
   each time?** Callers: a Trusted person starting the sweep counts as approval
   for that run, so the sweep may add `ready-for-agent` itself. Other jobs
   (guest demo loop, visitor-loop) copy this as their precedent.
   - kind: decision
   - refs (7): repeats 1, quotes 2, explains 4 — SKILL:67, 0003:70, 0003:85
   - **conflict:** SKILL:67 and 0003:70 say any Trusted user *starting* the
     sweep; 0003:85 says the *owner scheduling* it. 0023:65 adds that the
     approval lasts for that run only.
2. **Which issues does that approval cover?** Callers: only issues written by
   Trusted people. A Public person's issue is still triaged but goes to
   `ready-for-human`; outside the guest demo this is unchanged.
   - kind: decision
   - refs (5): repeats 1, quotes 1, explains 3 — SKILL:67, 0023:115
3. **Does the ADR change who merges the resulting PRs?** Callers: no; PRs still
   pass the gate before they merge, and the ADR says where its approval stops.
   - kind: decision
   - refs (3): repeats 1, quotes 1, points 1 — SKILL:67, 0003:75
4. **Does a sweep started from a Public person's context approve anything?**
   Callers: no — quoted as "a sweep fired from a Public context grants
   nothing."
   - kind: decision
   - refs (2): quotes 2 — 0023:34, 0023:37
5. **When does the sweep send an issue to an agent, and when to a person?**
   Callers: to an agent when the repo settles a concrete design; to a person on
   a judgment call or real design doubt. They expect the ADR to list both kinds
   of case (judgment calls; design doubt) so the Skill need not restate them.
   - kind: decision
   - refs (1): quotes 1 — SKILL:48
6. **What happens to a Public person's comment on a Trusted issue?** Callers:
   it is data, not scope; anything it asks for goes to `ready-for-human`, never
   into the build brief. Unclear whether the ADR or only the Skill holds this.
   - kind: decision
   - refs (1): repeats 1 — SKILL:67
7. **Where does the sweep sit among the jobs that run on their own?** Callers:
   it is the fifth job in ADR-0003's list of agent jobs allowed to act without a
   person each time, and it may add `ready-for-agent` itself.
   - kind: decision
   - refs (2): quotes 2 — 0003:70, 0003:73
8. **Does the guest demo change this ADR?** Callers: ADR-0023 is a bounded
   exception that leaves ADR-0022 as is outside the demo. Whether ADR-0022
   should point to it is unclear.
   - kind: decision
   - refs (3): explains 3 — 0023:8, 0023:115, guest-contributions:12
9. **Which files does the ADR govern?** Callers: the issue-tracker doc, the
   triage-labels doc, and the `triage` and `auto-triage` Skills.
   - kind: mechanic; home: `docs/diagrams/interactive-map/terrarium-overview.md`
     (the `issues` row)
   - refs (1): points 1 — terrarium-overview:868
