### 2. Conflicts

- **Who may read the Catalog?** `CONTEXT.md:238` says an Aggregator reads the Catalog "where a normal Tenant reads only its own Spaces". But the Blog, an ordinary Tenant, reads the Journal through `queryPages` and calls this sanctioned (`layers/blog/app/pages/t/blog/[space]/[...slug].vue:49`). The ADR must say whether any Tenant may use the read or only Aggregators may.
- **Which files are human-only because of ADR-0025?** ADR-0004's amendment names three files. Historical sessions add `shared/expand.ts` and `modules/routing.ts` (01VC6…:9), `shared/schemas/` (0136594…:9, which records a CLAUDE.md-vs-ADR-0025 contradiction) and the root `nuxt.config.ts` (015Bj…:206).
