## Checklist

1. **Claim: the site serves only content built from committed files; nothing
   is fetched from outside or live while it runs.** decision. 8 refs:
   explains 8. e.g. app/composables/catalog.ts:13,
   layers/commons/CONTEXT.md:36.
2. **Claim: one Nuxt app, in one repo and one container, serves every
   Tenant; a cross-Tenant view is an ordinary layer, not a separate runtime.**
   decision. 4 refs: explains 2, points 1, repeats 1. e.g. nuxt.config.ts:1,
   docs/adr/0025-...:132.
3. **Question: may a build run on the live server?** decision. **conflict.**
   ADR-0011 says ADR-0001 forbids it (production is an immutable image: tag a
   release, redeploy it, "nothing is created at runtime") and that ADR-0011
   relaxes this for a proof of concept. The ADR-0011 rule and guest-intake
   cite ADR-0001 itself for "the deploy runner is the one place a build runs
   at runtime". Mechanic home: `deploy/entrypoint.sh`. 7 refs: quotes 2,
   repeats 2, explains 2, points 1. e.g. docs/adr/0011-...:48,
   .claude/rules/adr-0011.md:12.
4. **Claim: content changes only with a new deploy, so caching a rendered
   page for the life of a deploy is safe.** decision. 2 refs: explains 2.
   e.g. docs/adr/0028-...:62, docs/research/content-client-queries-without-wasm.md:195.
5. **Question: what does isolation between Tenants and Spaces mean, and how
   strong is it?** Callers expect separate tables per Space so no Space's
   rows leak into another's request. decision. 3 refs: explains 1, points 1,
   enforces 1. e.g. app/pages/t/[tenant]/[space]/[...slug].vue:2,
   docs/adr/0023-...:19.
6. **Mechanic: each Tenant × Space × Collection is one SQLite table named
   `<tenant>_<space>_<collection>`, and that table is the unit of isolation.**
   Home: `shared/manifest.ts` (`collectionKey`). 2 refs: enforces 1,
   explains 1. e.g. shared/manifest.ts:155.
7. **Question: how does a request pick which Tenant and Space to serve?**
   Callers expect: by routing among already-built content; ADR-0006 quotes
   ADR-0001's options ("subdomain / path prefix / header") and picks the path.
   decision. 2 refs: explains 1, quotes 1. e.g. docs/adr/0006-...:17.
8. **Claim: Tenants, Spaces and collections are declared in files and built;
   nothing creates them while the site runs.** decision. 2 refs: repeats 1,
   quotes 1. e.g. docs/adr/0011-...:50.
9. **Claim: visitors have no way to save data that other visitors see (no
   accounts, comments, uploads).** decision. 1 ref: explains 1.
   e.g. .agents/skills/guest-intake/SKILL.md:88. Unclear whether ADR-0001
   states this or callers infer it from item 1.
10. **Claim: a Tenant is a Nuxt layer that extends the main app.** decision.
    2 refs: points 2. e.g. docs/adr/0018-...:8, docs/agents/tenant-layers.md:5.
    Unclear: both co-cite CONTEXT.md, so ADR-0001 may not be this fact's home.
