## Checklist

Most relied-on first.

1. **Claim: when a page's content fails to load in the browser, show an error
   dialog with a reload button instead of a blank page.** A reload is the only
   fix, because a failed load breaks the browser copy of that content until a
   full page load (which renders from the server).
   Kind: decision. Home: `app/components/ContentLoadErrorDialog.vue`, tested in
   `layers/blog/tests/e2e/blog.spec.ts`.
   Relied on by 6: quotes 2, explains 1, points 3.
   E.g. `app/components/ContentLoadErrorDialog.vue:15`, `docs/adr/0028-navigation-reads-server-payloads.md:58`.

2. **Claim: one failure reloads by itself: a failed download of a piece of the
   app's own code. It reloads once; if that fails too, the dialog shows. Every
   other failure gets the dialog, since a reload loop is worse than a dialog.**
   Kind: decision. Relied on by 5: quotes 1, explains 2, enforces 1, points 1.
   E.g. `app/composables/contentLoadRecovery.ts:5`, `layers/blog/tests/e2e/blog.spec.ts:16`.

3. **Claim: we do not patch @nuxt/content; the earlier client-DB patch was
   removed (2026-07-16).** One caller widens this to "no dependency patch" as a
   rejected option.
   Kind: decision. Relied on by 5: quotes 2, explains 2, points 1.
   E.g. `scripts/repro-236.ts:5`, `docs/research/content-client-queries-without-wasm.md:394`.

4. **Claim: why it fails.** Browser-side queries use a SQLite database that
   downloads each collection's data on first use; if that download fails, the
   collection stays empty for the rest of the page's life (issue #236).
   Kind: mechanic. Home: `scripts/repro-236.ts` reproduces it.
   Relied on by 5: quotes 3, points 2.
   E.g. `layers/blog/tests/e2e/blog.spec.ts:8`, `docs/adr/0028-navigation-reads-server-payloads.md:18`.

5. **Question: is ADR-0019 still in force or superseded?** **Conflict.**
   `layers/midden/app/utils/strata.ts:70` ("ADR-0019, superseded") and
   `the-nuxt-content-patch.yml:36` ("before it was marked superseded") say it is
   superseded. `docs/adr/0028-navigation-reads-server-payloads.md:58` ("ADR-0019's recovery ... stays")
   and the code comments cite it as the live rule for the dialog and auto-reload.
   Kind: decision. Relied on by 6: explains 1, points 2, quotes 3 (implicitly live).

6. **Mechanic: the automatic reload happens at most once per path within Nuxt's
   reload time limit, and only in the browser.**
   Kind: mechanic. Home: `app/composables/contentLoadRecovery.ts`, `app/utils/chunkRecovery.ts`.
   Relied on by 2: explains 1, enforces 1.
   E.g. `app/composables/contentLoadRecovery.ts:5`, `layers/blog/tests/e2e/blog.spec.ts:16`.

7. **Claim: the recovery is wired once, in the dialog every page already

   Kind: decision. Home: `app/components/ContentLoadErrorDialog.vue`.
   Relied on by 2: quotes 1, explains 1.
   E.g. `app/components/ContentLoadErrorDialog.vue:15`.
