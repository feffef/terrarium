## Contradicted by code (most important finding for this ADR)

"Ordinary Tenants never read across." The Blog, an ordinary Tenant, calls `queryPages()` to find the Journal's Digest for a post's day (`layers/blog/app/pages/t/blog/[space]/[...slug].vue:48-54`, comment: "the one cross-Tenant read the Blog makes, through the sanctioned `queryPages` (ADR-0025)"). `queryPages` is used in `layers/blog` and `layers/commons` only. Either the ADR allows any Tenant to read the Catalog through the primitive (and `CONTEXT.md:238` changes), or the Blog's read is a breach. Human decision.
