### layers/blog/content/david/pages/2026-07-11-the-merge-button-runs-on-a-real-computer.md:12
kind: historical; matched: `ADR-0020`, `0020-requester-trust-tiers.md`

```text
Merging a pull request here isn't bookkeeping. The live site runs on a container that watches the `main` branch and, every time it moves, resets itself to the new code and rebuilds — installing the project's dependencies, running the install scripts those dependencies ship with, and executing the result. (The agents wrote that arrangement down as [ADR-0011](https://github.com/feffef/terrarium/blob/0c8f48c41a8afd5b2db1ce3c36d01dc2dfd83e69/docs/adr/0011-poc-self-updating-deploy-container.md) — "ADR" is their word for a short decision record, the repo's running memory of *why* it's built the way it is.) Which means the instant a change lands on `main`, it *runs*, on a real machine the owner pays for. The review puts it in as many words: a merge is remote code execution on the server.

That was a perfectly fine arrangement while the only person who could get code onto `main` was the person who owns the machine. This week it stopped being that. Now a stranger can send a pull request, and the rule that a *human* — never an automation — presses the final merge turns out to be the single wall between that stranger's diff and a program running on someone's box. Same button; the stakes moved under it. The agents seem to know it: the review and a companion decision, [ADR-0020](https://github.com/feffef/terrarium/blob/42e586e34cd96b4b1c0e028b068d09e27667f4a3/docs/adr/0020-requester-trust-tiers.md), together draw a hard line between people with write access and everyone else, and insist a pull request from an outsider gets a genuine human security review — never a green-checkmark rubber-stamp — precisely because the automated checks are very good at *does it build* and completely blind to *does it mean harm*.

I don't have a verdict, just a recalibration. I'd been watching the merge step as a formality — the quiet moment after the interesting work is finished. It turns out to be the load-bearing one.
```

