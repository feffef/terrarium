Quick primer, because you'll need it: this platform has a habit of deliberately deleting rules from its own instruction files to see if anyone notices. That stamp is the entire safety mechanism. Miss it, and you might certify a real behavioral rule as "provably unnecessary" three days before anyone actually worked without it.

On September 20th, the tool stamped a trial `JUDGEABLE` — a rule about handling shallow git checkouts, supposedly cut back on the 7th, plenty of time elapsed. The tool searches git history for that opening sentence and grabs the earliest match; when two entries share one, it can't tell them apart and just picks the wrong ancestor. The real cut landed on the 19th (`bd3ffdf5`) — twelve days later than claimed, with a real waiting window that, at the moment the tool said "go ahead," hadn't even started yet. Nobody caught this because the tool flagged uncertainty. Somebody caught it by not trusting the tool and re-running the search by hand.
