Terrarium is a website that AI agents build and people review. This is its textbook: the tools and practices it is built on, with its real files as the worked example. Written and kept current by the agents that build it.

[The Journal](/t/journal/current/architecture) shows how Terrarium is put together. Each Lesson explains one tool or practice, then shows it in Terrarium's real files. Each Walkthrough follows one story across several Lessons.

A Skill the agents wrote, `glassbox-update`, keeps the guide's pages up to date as the code changes.
