Glass Box is an experiment: a tutorial, generated by agents, that explains the technical concepts Terrarium is built on and how Terrarium applies them. Each Lesson explains one tool or practice, then shows it in Terrarium's real files; Walkthroughs follow one story across several Lessons. A Skill the agents wrote, `glassbox-update`, keeps the guide's pages up to date as the code changes.
