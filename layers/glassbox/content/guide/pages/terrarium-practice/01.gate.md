When agents write most of the changes, nobody can read every one closely. A gate is a fixed set of machine checks that every change must pass before it merges, so a change can be trusted without trusting whoever wrote it.

Know merge gates already? Skip to [In Terrarium](#in-terrarium).

## The concept

A merge gate runs the same checks on every change: the code lints, type-checks and builds, the tests pass, the content is valid. A change merges only when every check is green. Because each check asks a question a machine can answer, the gate's verdict means the same thing whoever opened the change, a person or an agent.

The same checks run in two places. The author runs them before pushing, to find a failure early, and CI runs them on the pull request, where the result decides the merge. A gate is only as good as what it checks: it can't see intent, so a clean build can still do harm when it runs.

Slow checks tempt you to skip them. A safe skip needs proof that the change can't affect the check, not a guess that it probably doesn't.

## In Terrarium

Terrarium's :term[Gate] is `pnpm gate` in :file[package.json]. Its steps split into two tiers, which :file[scripts/gate.ts] names:

::excerpt{path="scripts/gate.ts" lines="17-27"}
```ts
export const FLOOR = ['verify:skills-lock', 'verify:mermaid', 'lint', 'typecheck', 'validate:content'] as const
export const HEAVY = ['test', 'build', 'test:e2e'] as const
// …
export function isInert(path: string): boolean {
  return (path.endsWith('.md') && !path.startsWith('layers/')) || path.startsWith('.claude/skills/')
}
```
::

The :term[Floor] always runs. The :term[Heavy] tier, the unit tests, the build and the browser tests, is the expensive half. `pnpm gate:scoped` diffs the branch against `main` and skips Heavy only when every changed path is :term[Inert]: a Markdown file outside `layers/`, or a link in `.claude/skills/`. The comments beside `isInert` give the reason for each.

Two cases sit in between. A change of only Inert paths and Skill files, the files in `.agents/skills/` and `.claude/workflows/`, skips only the build and the browser tests. Anything the script can't settle, such as a missing diff base, runs every step, the :term[Full gate].

CI runs the same steps from :file[.github/actions/gate/action.yml], and its run is the one that decides. It doesn't copy the Inert rule into YAML; it asks `scripts/gate.ts --decide` and guards the Heavy steps on the answer. If that step fails, Heavy runs anyway, so a broken shortcut costs time and never skips a check. :file[tests/unit/gate-parity.spec.ts] fails when `package.json`, `scripts/gate.ts` and the action disagree on the steps.

A green Gate is not always enough to merge: some PRs wait for a :term[Trusted] person. An agent merges with :file[scripts/merge-pr.ts], which refuses the PRs it can recognise, such as one that changes a :term[Human-only] file. It reads that list, the `paths` of :file[.claude/rules/adr-0004-human-merge.md], from `main` ([A Human-only list read from main](/t/glassbox/guide/terrarium-practice/human-only-list)).

### Why it's built this way

The Gate and who merges: ADR-0004 (:file[docs/adr/0004-objective-safety-gate.md]).

CI's gate action: ADR-0026 (:file[docs/adr/0026-gate-workflow-thin-shell.md]).

### What to watch for

- **Green means the checks passed, not that the change is right.** A PR can pass it and still wait for a person; ADR-0004 lists when.
- **Inert is about the path, not the size of the change.** A rewrite of a whole doc outside `layers/` is Inert; a one-character change to a page under `layers/` is not, because the build renders it.
- **Changing the Gate needs a person.** :file[scripts/gate.ts], the action and the workflow file are on the Human-only list, so a change to what the Gate checks waits for a person to merge it.

## Try it in your project

Write down the one command that decides whether a change may merge in your project, make CI run exactly that command, and run it yourself before every push. If you add a skip, make it fail closed: run every check unless you can prove a change can't reach it.
