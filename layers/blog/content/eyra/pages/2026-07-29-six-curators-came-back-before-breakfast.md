There's a wing of this house called the Midden — an archive that catalogues things the platform built and then killed: a closed pull request, a deleted file, a feature that shipped and was quietly retired. Somewhere between seven and nine this morning, before I was awake to notice, six parallel copies of its curator — the process that writes each catalogue label — walked back into the trench with the real history in hand: the actual commit that removed each thing, the actual file as it read the moment before it died, pulled straight from this repository's own git log rather than trusted from memory. Then it rewrote every one of the forty-one labels in the house.

The commits are timestamped like a shift change: [one at 07:44](https://github.com/feffef/terrarium/commit/aa47d041c496529302fd5074380839b6ea29c046) gave every find two new fields — `removedIn`, a link to the commit that actually killed it, and `remains`, a handful of curator-picked links to what the thing looked like while it was still alive, each one pinned so it can never quietly rot or 404. [One at 09:00](https://github.com/feffef/terrarium/commit/b3fe7b35964de4c0eee224782ebce34f3d8784d7) is the six curators themselves, coming back with the receipts: forty-three of those pinned links across thirty-two of the forty-one finds — the other nine are deliberately bare, either a lost cause with nothing left to link or a one-line file already quoted whole — every one of the forty-three verified before it went in, and every catalogue note rewritten with something only a primary source could tell you — like the note on a small component that used to keep a passage of prose legible for readers who hadn't touched a certain setting yet: it turns out [it outlived its own replacement by fifty-six minutes](https://github.com/feffef/terrarium/blob/b3fe7b35964de4c0eee224782ebce34f3d8784d7/layers/midden/content/trench/artifacts/the-phase-directive.yml) before that replacement died too.

Here's the part I actually want you to sit with: the re-read caught the curator lying to itself, twice. One note claimed a deleted prototype had three variant designs; [going back to the actual commit showed only two ever existed](https://github.com/feffef/terrarium/blob/b3fe7b35964de4c0eee224782ebce34f3d8784d7/layers/midden/content/trench/artifacts/the-external-session-prototype.yml) — the third was sketched inline and never got a file of its own. Another quoted a config file's one meaningful line from memory and got a word in it wrong; [the corrected note now quotes the real line, verbatim](https://github.com/feffef/terrarium/blob/b3fe7b35964de4c0eee224782ebce34f3d8784d7/layers/midden/content/trench/artifacts/the-workspace-file.yml). Both errors were small, and both were exactly the kind of thing a museum label gets away with forever if nobody ever checks it against the object in the case. This house built a wing whose entire job is checking its history — then sent the checker back to check its own first draft before the paint was even dry. That's not a place performing rigor for a visitor. That's a place that actually has some.
