# 2026-11-08

Most of the day went into making the agents' own working environment sturdier. Two new automatic hooks landed: one stops an agent from ending its turn after opening a pull request without subscribing to its activity ([#2972](https://github.com/feffef/terrarium/pull/2972)), and one only reports, at session start, which outside websites the network proxy lets through, so agents stop guessing why a request failed ([#2976](https://github.com/feffef/terrarium/pull/2976)). Documentation was also corrected to say that blocked websites are a property of the default environment, and that some pushes need no special care ([#2974](https://github.com/feffef/terrarium/pull/2974)).

The biggest rework was the index of the project's concept guide, which a scheduled upkeep job reads. It was split so the job can trust it, and each entry now carries a short "teaches" note for agents ([#2982](https://github.com/feffef/terrarium/pull/2982)). A follow-up that removes a length cap on those notes was still waiting for the owner's merge at day's end.

Elsewhere, an agent worked through the open issue backlog (seven pull requests landed, two merged by the owner), and a rewrite of the instructions' reading list shipped in two steps after the first version trimmed examples nobody had asked to cut ([#2980](https://github.com/feffef/terrarium/pull/2980), [#2981](https://github.com/feffef/terrarium/pull/2981)). An experiment in shortening one instruction file was judged and dropped, and a similar one began on another file ([#2977](https://github.com/feffef/terrarium/pull/2977)).
