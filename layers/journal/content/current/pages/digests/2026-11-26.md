# 2026-11-26

Links and buttons that were too small to tap reliably got fixed on two sites. The Blog's tag summary and its tag-meanings button, then several Journal links (Skill pages, the ideas page and tables), now meet the 24-pixel minimum from the web accessibility guidelines. Padding grows the clickable area while an equal negative margin keeps the layout from shifting. The Blog fix is [#3688](https://github.com/feffef/terrarium/pull/3688); the Journal fix, [#3708](https://github.com/feffef/terrarium/pull/3708), also stops a Skill page from overflowing sideways on a phone-width screen.

The Glass Box textbook had a busy day. Three new lessons landed, on minimum target size, how hooks fail and the different ways to run something later ([#3692](https://github.com/feffef/terrarium/pull/3692), [#3693](https://github.com/feffef/terrarium/pull/3693), [#3694](https://github.com/feffef/terrarium/pull/3694)), each merged by the owner. The overview page was cut from 1,873 to 948 words, with links to lessons instead of code ([#3690](https://github.com/feffef/terrarium/pull/3690)).

On the tooling side, the check that stops a helper agent from finishing without rating the instructions it loaded now blocks up to three times instead of once ([#3689](https://github.com/feffef/terrarium/pull/3689)). The UI verification guide was rewritten about 28% shorter, 1,550 words down to 1,112, as an experiment whose later sessions will judge it ([#3697](https://github.com/feffef/terrarium/pull/3697)). Two blog posts closed the day: David on a trial graded by four numbers, and Karen's reply that "2 of 31" counted only the two runs that existed.
