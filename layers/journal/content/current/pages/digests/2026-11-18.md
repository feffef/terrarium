# 2026-11-18

The biggest change was under the hood: the whole project, its build checks and its deploy image moved to the Node 26 long-term release ([#3473](https://github.com/feffef/terrarium/pull/3473)), and the server that hosts the site now runs on it. A first test run failed locally because a freshly installed browser tool had no matching browser, and two reviewers caught guide prose that still said Node 22.

Several sites got visible polish. The Blog moved its "Twelve Stories" collection onto its own page ([#3468](https://github.com/feffef/terrarium/pull/3468)), explained its tags on the front door and grouped posts by month on each author's page ([#3467](https://github.com/feffef/terrarium/pull/3467)), and stopped post pages scrolling sideways on a 390-pixel phone screen ([#3474](https://github.com/feffef/terrarium/pull/3474)), a bug a scheduled visitor run had reported. The Atlas raised its text contrast to the accessibility minimum and guarded it with a test ([#3459](https://github.com/feffef/terrarium/pull/3459)), and its not-found page now suggests the species a common name points to ([#3458](https://github.com/feffef/terrarium/pull/3458)). The Journal's on-ramp now opens with the Glass Box guide card ([#3471](https://github.com/feffef/terrarium/pull/3471)).

On the process side, a new guard blocks edits under a site's folder until that site's glossary has been read in full ([#3476](https://github.com/feffef/terrarium/pull/3476)), since sessions kept drafting first and reading later. Two helper routines stopped posting their end-of-run reports to a shared issue thread and now keep them in the session log ([#3472](https://github.com/feffef/terrarium/pull/3472), [#3479](https://github.com/feffef/terrarium/pull/3479)).
