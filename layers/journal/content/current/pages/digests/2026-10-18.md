# 2026-10-18

Cost was the theme of the day. After a session found that token usage and price are available for every scheduled job run, the weekly skills check began reporting them ([#2243](https://github.com/feffef/terrarium/pull/2243)). The first version only showed averages, so a follow-up kept each run as its own record with a 40-day backfill ([#2246](https://github.com/feffef/terrarium/pull/2246)), and the records moved out of the skills inventory into a dedicated Journal collection ([#2247](https://github.com/feffef/terrarium/pull/2247)). A new Routine costs page charts them ([#2253](https://github.com/feffef/terrarium/pull/2253)). Two blog personas picked up the story, noting that the agents' cost records changed shape twice in under three hours, that the 30-run cap deletes the four priciest runs first, and that the priciest session never made the ledger ([#2248](https://github.com/feffef/terrarium/pull/2248), [#2249](https://github.com/feffef/terrarium/pull/2249), [#2250](https://github.com/feffef/terrarium/pull/2250)).

Glass Box, the site that teaches how the project works, moved from a pinned focus into the regular visitor-style review rotation, replacing the mobile row ([#2251](https://github.com/feffef/terrarium/pull/2251)). That review added a sidebar and a pointer to the terms strip ([#2255](https://github.com/feffef/terrarium/pull/2255)) and a real example for its "A change goes live" walkthrough ([#2256](https://github.com/feffef/terrarium/pull/2256)). The owner then removed the "Try it" page and the session-log explainer ([#2257](https://github.com/feffef/terrarium/pull/2257)). Separately, the Platform's navigation test kept timing out on a slow first render of the home page, so a fix warms that page's data first ([#2258](https://github.com/feffef/terrarium/pull/2258)).

Elsewhere, the Journal's History page gained a "Simplifying the rules" period covering 3–17 October, with table rows linking to their sections ([#2259](https://github.com/feffef/terrarium/pull/2259), [#2260](https://github.com/feffef/terrarium/pull/2260)). Only the triage Skills may now mark issues as ready to work on; other Skills file them for triage ([#2254](https://github.com/feffef/terrarium/pull/2254)).
