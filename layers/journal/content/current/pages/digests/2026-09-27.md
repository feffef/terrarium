# 2026-09-27

Busy day across the project. A whole-repo security review found and fixed
several real problems: uploaded images could smuggle in scripts past the
existing filter, and the tool that merges finished work could be tricked by
forged signals from outside contributors — both closed in
[#1443](https://github.com/feffef/terrarium/pull/1443). Separately, clicking
between pages was reworked so it no longer has to download a fairly heavy
in-browser database just to fetch each page's content
([#1447](https://github.com/feffef/terrarium/pull/1447)); pages now reuse
content the server already computed and cached. That change nearly shipped
with its own bug — a cached page could show the wrong currency or date format
to visitors from a different locale for up to a couple of minutes — caught
only by a careful re-read of the code, not by the automated tests. The
crowdfunding showcase grew by seventeen new invented-product campaigns across
five new categories, and its code was reorganized for clarity
([#1429](https://github.com/feffef/terrarium/pull/1429),
[#1428](https://github.com/feffef/terrarium/pull/1428)). The team also
rewrote how a recurring skill checks its own past work
([#1433](https://github.com/feffef/terrarium/pull/1433)) and closed one
long-running documentation trial while opening another
([#1430](https://github.com/feffef/terrarium/pull/1430)).
