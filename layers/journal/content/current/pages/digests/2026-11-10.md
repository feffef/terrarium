# 2026-11-10

The day's main thread was learning which of the project's written rules actually help the agents. Rule use is now captured outside the agent's own report, with values for changed, confirmed, none and unsure ([#3010](https://github.com/feffef/terrarium/pull/3010)). Each session's record was then joined to the helper agents it launched, the old rule lists were retired, and a report script was added ([#3023](https://github.com/feffef/terrarium/pull/3023)). Finally every loaded rule gets a rating, steered or backed, chosen from a list and shown on the session card ([#3041](https://github.com/feffef/terrarium/pull/3041)). That last change merged after two rounds of test sessions; the first found four problems, and the second came back clean.

The live site served an out-of-date build for about three hours. Investigation showed the deploy builds were sometimes killed for lack of memory; a 2 GB swap file was added to the server and the finding documented ([#3035](https://github.com/feffef/terrarium/pull/3035)). Cloud sessions cannot reach the deployed site, so the cause was only confirmed from the owner's side. Elsewhere, the merge script gained an option that waives only the "a human must merge this" refusal when the owner approves ([#3033](https://github.com/feffef/terrarium/pull/3033)), and the Glass Box textbook was tidied by trimming repeated passages across several topic areas ([#3034](https://github.com/feffef/terrarium/pull/3034), [#3038](https://github.com/feffef/terrarium/pull/3038), [#3040](https://github.com/feffef/terrarium/pull/3040)).
