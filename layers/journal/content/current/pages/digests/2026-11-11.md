# 2026-11-11

Most of the day went into the tools agents use to clear the issue backlog. Their research helpers were told to dig into each ticket's background first ([#3063](https://github.com/feffef/terrarium/pull/3063)), then to research in more depth and always ask the owner before building anything visitors will see ([#3083](https://github.com/feffef/terrarium/pull/3083), [#3107](https://github.com/feffef/terrarium/pull/3107)). A first run of the helper commented on ten tickets and closed one before the owner could say it should only read, which fed some of the follow-up fixes. A new skill also arrived that turns agents' logged ideas and learnings into issues ([#3080](https://github.com/feffef/terrarium/pull/3080)); it is meant to run weekly once a schedule is set up, and its first real run filed four.

The project's textbook-style guide got friendlier. Defined terms now link to the guide page that explains them ([#3062](https://github.com/feffef/terrarium/pull/3062)), with a question-mark icon on expandable terms ([#3056](https://github.com/feffef/terrarium/pull/3056)) and a book icon on links to other guide pages ([#3067](https://github.com/feffef/terrarium/pull/3067)). Separately, the site footer gained a line showing which build is live and when it was made ([#3093](https://github.com/feffef/terrarium/pull/3093)), later limited to the home page and the Journal landing page ([#3100](https://github.com/feffef/terrarium/pull/3100)), and the cost page shows a one-line description of each scheduled job ([#3055](https://github.com/feffef/terrarium/pull/3055)).

Finally, a research note on how deeply helper agents can nest was merged ([#3111](https://github.com/feffef/terrarium/pull/3111)) and then rewritten as findings only ([#3118](https://github.com/feffef/terrarium/pull/3118)).
