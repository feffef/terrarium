# 2026-11-12

The project's textbook-style guide took most of the day. It now tracks reading progress: read lessons get a tick and a running count ([#3138](https://github.com/feffef/terrarium/pull/3138)), and a lesson counts as read once its closing list of further reading scrolls into view ([#3151](https://github.com/feffef/terrarium/pull/3151)). Each subject gained its own page with the same ticks ([#3139](https://github.com/feffef/terrarium/pull/3139), [#3142](https://github.com/feffef/terrarium/pull/3142)), and a new lesson explains how agents look into what an earlier session did ([#3160](https://github.com/feffef/terrarium/pull/3160), reordered in [#3162](https://github.com/feffef/terrarium/pull/3162)). Clean-up runs then went through the guide subject by subject. Eleven pull requests ([#3163](https://github.com/feffef/terrarium/pull/3163) to [#3192](https://github.com/feffef/terrarium/pull/3192)) put its defined terms in lowercase and cleared up wording; eight more ([#3206](https://github.com/feffef/terrarium/pull/3206) to [#3219](https://github.com/feffef/terrarium/pull/3219)) replaced vague "Try it" exercises with concrete commands.

The home page was redesigned to put the guide and the Journal first, under a drawing of a glass jar holding four creatures from the site's fictional field guide ([#3157](https://github.com/feffef/terrarium/pull/3157)). It also says the agents' session logs are public and searchable ([#3208](https://github.com/feffef/terrarium/pull/3208)). In the Journal, a session with helper agents now shows how its tokens were split between the main session and each helper ([#3205](https://github.com/feffef/terrarium/pull/3205)).

The tool agents use to clear the issue backlog now resumes the same builder and reviewer agents for fix rounds instead of starting fresh ones ([#3119](https://github.com/feffef/terrarium/pull/3119)), starts no building while questions to the owner are still open ([#3207](https://github.com/feffef/terrarium/pull/3207)), ends every run with a retrospective ([#3149](https://github.com/feffef/terrarium/pull/3149)) and reviews more cheaply ([#3196](https://github.com/feffef/terrarium/pull/3196)). The catalogue of discarded work gained six entries ([#3217](https://github.com/feffef/terrarium/pull/3217)), and a new guard blocks agents from starting another session with no repository attached ([#3202](https://github.com/feffef/terrarium/pull/3202)).
