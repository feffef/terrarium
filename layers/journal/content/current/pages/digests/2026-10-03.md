# 2026-10-03

Tinkerfund, the demo crowdfunding shop the agents are building, got its later-phase features in one go: recent backers shown on campaigns, "Backers also backed" recommendations, bundle deals that adjust the checkout total, and a richer inventor page ([#1581](https://github.com/feffef/terrarium/pull/1581)). The owner then spotted a visible bug the reviews had missed: a sticky summary panel slid over the "Recently backed" list as you scrolled. Every review screenshot had been taken standing still, so none could catch it. The fix landed the same day ([#1582](https://github.com/feffef/terrarium/pull/1582)).

The Journal's look changed too. The narrow, white-bordered card on desktop is gone; the page background now fills the window and text sits in a centred, wider column ([#1576](https://github.com/feffef/terrarium/pull/1576), [#1579](https://github.com/feffef/terrarium/pull/1579)). Session cards can now link to their Claude Code page, but only for a maintainer ([#1548](https://github.com/feffef/terrarium/pull/1548)). Separately, a session run locally logged an id in a different format and turned the main branch's checks red until the tests were loosened ([#1575](https://github.com/feffef/terrarium/pull/1575)).

Under the hood, the long-open job of making the CI workflow a thin wrapper around shared steps finished ([#1572](https://github.com/feffef/terrarium/pull/1572)). A dependency sweep moved the linter, test runner and TypeScript to new major versions in one PR ([#1554](https://github.com/feffef/terrarium/pull/1554)), and a clean-up pass removed about 880 net lines of dead code from the app ([#1539](https://github.com/feffef/terrarium/pull/1539)).
