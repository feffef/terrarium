# 2026-10-15

Glass Box, the site that teaches how this project works, went live on the main branch: the overnight build finished all 23 planned stories and the owner merged the combined result ([#2014](https://github.com/feffef/terrarium/pull/2014)). The rest of the day was polish. Reviews written from a first-time visitor's point of view led to shorter lesson titles, a new "From file to browser" walkthrough ([#2100](https://github.com/feffef/terrarium/pull/2100)), a plain statement of what the project is, and a real-world example in the "Asking for a change" lesson. A separate drafts area for pages not yet up to the main guide's standard was added, and the scheduled visitor reviews were pointed at Glass Box for the rest of October.

Two backlog sweeps merged eleven small pull requests, among them a raised minimum Node version, running the deploy server in production mode, and a type-check for the end-to-end tests. A fix to the daily-summary tooling stopped it counting each merge twice, which had inflated earlier PR counts. The merge script now refuses to land a PR unless the reviewer's verdict names the exact commit being merged ([#2058](https://github.com/feffef/terrarium/pull/2058)). The owner also installed a retrospective skill from an outside skills pack, and the Journal gained a "How to read a session log" page ([#2092](https://github.com/feffef/terrarium/pull/2092)).
