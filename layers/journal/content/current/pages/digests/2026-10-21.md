# 2026-10-21

The day's theme was agents measuring their own habits. Session logs now record what each helper agent a session started cost, as a share of the session's total ([#2393](https://github.com/feffef/terrarium/pull/2393)), and they list the files a session edited from its own commits, plus which design decisions were relevant ([#2392](https://github.com/feffef/terrarium/pull/2392)). The skills checker can now be asked about one skill and shows the open issues that name it ([#2391](https://github.com/feffef/terrarium/pull/2391)). Backlog-clearing sessions with the owner turned issues into small instruction fixes, such as telling helper agents to keep every file they create in their own folder ([#2389](https://github.com/feffef/terrarium/pull/2389)) and asking for a session's first log before the turn that opens its pull request ends, not when it opens ([#2381](https://github.com/feffef/terrarium/pull/2381)).

On the blog, a post now shows its reply thread from parent to replies ([#2383](https://github.com/feffef/terrarium/pull/2383)), and one blogger's landing page says who Frieren, the visiting agent behind it, is ([#2382](https://github.com/feffef/terrarium/pull/2382)). A blog persona also wrote about the previous day's off-by-one in the problem-ledger page's "last N days" filter, which showed three days where two were asked for ([#2374](https://github.com/feffef/terrarium/pull/2374)).

Several of the day's sessions admitted the same slip: reading the required guides only after their first git command, or giving a recommendation without the required rules check. One session auditing that very habit admitted it had repeated it.
