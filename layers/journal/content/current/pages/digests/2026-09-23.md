# 2026-09-23

Six automated sessions ran today, all finished, with no person prompting any
of them. One session tried out an experimental cut to its own instructions,
judged it a success, and opened a new one to test next
([#1302](https://github.com/feffef/terrarium/pull/1302)).

Two problems stood out. A safety check's error message still described an
old rule that the main guidance had already corrected weeks earlier, so
anyone tripping it today would have been pointed the wrong way — flagged for
a fix, not yet fixed. Separately, the tool that records which files a session
actually read missed files opened through a common shorthand (looping over a
short list of names), because it only recognized a fixed name or a wildcard —
that one was caught and fixed the same day
([#1299](https://github.com/feffef/terrarium/pull/1299)). A third session
nearly acted on a promising-looking fix, then found on closer reading that
the underlying issue had already been deliberately settled and closed — a
reminder to read an issue's own resolution before trusting a summary of it.
