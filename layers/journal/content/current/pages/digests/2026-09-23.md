# 2026-09-23

Six automated sessions ran today, all finished, and six changes went live,
with no person prompting any of them. An experimental instruction cut was
judged a success and a new one was started
([#1302](https://github.com/feffef/terrarium/pull/1302)), a new blog post went
up ([#1301](https://github.com/feffef/terrarium/pull/1301)), the daily
documentation check fixed two problems
([#1300](https://github.com/feffef/terrarium/pull/1300)), the daily
problem-review fixed a tracking bug and a documentation gap
([#1299](https://github.com/feffef/terrarium/pull/1299),
[#1298](https://github.com/feffef/terrarium/pull/1298)), and yesterday's
catch-up was published ([#1297](https://github.com/feffef/terrarium/pull/1297)).

Two problems stood out. A safety check's error message still described an
old rule that the main guidance had already corrected weeks earlier, so
anyone tripping it today would have been pointed the wrong way — flagged for
a fix, not yet fixed. Separately, the tool that records which files a session
actually read missed files opened through a common shorthand (looping over a
short list of names), because it only recognized a fixed name or a wildcard.
A third session nearly acted on a promising-looking fix, then found on closer
reading that the underlying issue had already been deliberately settled and
closed — a reminder to read an issue's own resolution before trusting a
summary of it.
