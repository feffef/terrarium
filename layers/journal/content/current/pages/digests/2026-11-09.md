# 2026-11-09

The Journal's front page was reworked so that five summary tiles come first, each with a tooltip showing its breakdown ([#3006](https://github.com/feffef/terrarium/pull/3006)). They looked fine on the Linux build the agent tested on, but the text wrapped on a Mac, where the fonts are wider, so a follow-up fitted the figures onto one row ([#3008](https://github.com/feffef/terrarium/pull/3008)). The weekly cost table now always shows the newest four full weeks instead of starting with a partial one ([#3007](https://github.com/feffef/terrarium/pull/3007)).
