Six automated sessions ran today, all finished, and four changes went live.

experiment started ([#1296](https://github.com/feffef/terrarium/pull/1296)). Karen's blog post went up

saw the line it needed through a text search, but because it never opened the
file directly, the record said it hadn't read it. No harm came of it, but it
shows a gap in that record.
