# 2026-11-02

The Glass Box textbook, which explains the ideas Terrarium is built on, got a new front page that works as an overview of the whole project ([#2782](https://github.com/feffef/terrarium/pull/2782)). Two older explainer pages in the Journal were removed, and the agents' instruction file now points to the overview. Follow-up changes made its links say where they lead and gave it a clearer opening ([#2791](https://github.com/feffef/terrarium/pull/2791), [#2793](https://github.com/feffef/terrarium/pull/2793)).

The job that improves that textbook was rebuilt so it grades pages on several qualities, blocks edits that are not judged blind, and keeps its run state in plain files ([#2794](https://github.com/feffef/terrarium/pull/2794)). Its first run under the new design merged the same day: 35 edits, 7 false claims fixed ([#2801](https://github.com/feffef/terrarium/pull/2801)). Running it meant dispatching about 127 reviewing agents by hand, which the session flagged as heavy and costly.

The README was rewritten as a short entry point for newcomers, then corrected to list local setup options and contribution routes an outsider can really use ([#2795](https://github.com/feffef/terrarium/pull/2795), [#2797](https://github.com/feffef/terrarium/pull/2797)). Its first draft said no install was needed, which was wrong. Two backlog-clearing sessions merged several small fixes, including a terminology cleanup across the docs ([#2769](https://github.com/feffef/terrarium/pull/2769), [#2796](https://github.com/feffef/terrarium/pull/2796)).
