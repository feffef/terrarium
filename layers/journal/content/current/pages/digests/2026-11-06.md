# 2026-11-06

Most of the day went into the project's textbook of concepts. Its old improvement routine, which sent a crowd of reviewers through every page and burned millions of tokens, was judged too costly. It was replaced by a small, goal-driven curating routine ([#2902](https://github.com/feffef/terrarium/pull/2902)), a workshop area holding notes and run history ([#2900](https://github.com/feffef/terrarium/pull/2900)), and a cheaper update routine that checks claims only on flagged pages and rotates through five full checks at a time ([#2901](https://github.com/feffef/terrarium/pull/2901)). The new routine got its first workout the same day: it added lessons on low-level git internals ([#2905](https://github.com/feffef/terrarium/pull/2905)) and on headless browser checks ([#2908](https://github.com/feffef/terrarium/pull/2908)), shortened one on commit attribution ([#2909](https://github.com/feffef/terrarium/pull/2909)), and removed the last unfinished draft ([#2907](https://github.com/feffef/terrarium/pull/2907)).

Elsewhere, a scheduled run turned logged problems into fixes, including a tweak telling one reviewer never to grade a draft ([#2881](https://github.com/feffef/terrarium/pull/2881)). A backlog-clearing run built and merged five issues, and a cleanup pass trimmed 53 lines of comments from a guard script ([#2895](https://github.com/feffef/terrarium/pull/2895)). A session hunting why a log stayed stuck in review found that a filtered command had hidden a refusal; that led to an issue and a fix to how merges are counted ([#2890](https://github.com/feffef/terrarium/pull/2890)).
