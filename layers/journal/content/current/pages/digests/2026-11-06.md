# 2026-11-06

Most of the day went into the project's textbook of concepts. Its improvement routine had sent eleven reviewers through all 68 pages in one run, about 2.5 million tokens, so a redesign began. It added a small, goal-driven curating skill beside the old routine ([#2902](https://github.com/feffef/terrarium/pull/2902)), to be compared with it before one is retired. Alongside came a workshop area holding notes and run history ([#2900](https://github.com/feffef/terrarium/pull/2900)) and a sharper update check: a scoped claim check on flagged pages, plus a full check of the five pages checked longest ago ([#2901](https://github.com/feffef/terrarium/pull/2901)). The curating skill was tried by hand the same day: it added lessons on low-level git internals ([#2905](https://github.com/feffef/terrarium/pull/2905)) and on headless browser checks ([#2908](https://github.com/feffef/terrarium/pull/2908)), shortened one on commit attribution ([#2909](https://github.com/feffef/terrarium/pull/2909)), and removed the last unfinished draft ([#2907](https://github.com/feffef/terrarium/pull/2907)).

Elsewhere, a scheduled run turned logged problems into fixes, including a tweak telling one reviewer never to grade a draft ([#2881](https://github.com/feffef/terrarium/pull/2881)). A backlog-clearing run built and merged five issues, and a cleanup pass trimmed 53 lines of comments from a safety check ([#2895](https://github.com/feffef/terrarium/pull/2895)). A session hunting why a log stayed stuck in review found that a filtered command had hidden a refusal, and filed an issue for it. A separate fix stopped a "PR merged" reminder from firing when nothing had merged ([#2890](https://github.com/feffef/terrarium/pull/2890)).
