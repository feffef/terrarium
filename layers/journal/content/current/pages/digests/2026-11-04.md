# 2026-11-04

The biggest change was to the working rules: agents used to open a pull request at their first push, and now they [push early and open the PR only after review and the automated checks pass](https://github.com/feffef/terrarium/pull/2828). That meant repointing several docs that cited the old wording, and a later textbook sync reworded a handful of guide pages to match.

On the dashboard side, [#2845](https://github.com/feffef/terrarium/pull/2845) makes the Routine charts show the chosen metric instantly above whichever bar you hover. The owner had asked for the selected metric, not always cost, and the agent had to correct its first assumption. A backlog-clearing session also merged [#2840](https://github.com/feffef/terrarium/pull/2840) and [#2841](https://github.com/feffef/terrarium/pull/2841), the latter a small script so a review verdict's commit id is pasted rather than typed. Another session made a recorded fix reopen an already-accepted entry in the list of recurring problems ([#2846](https://github.com/feffef/terrarium/pull/2846)), reopening five entries.

The largest run was a delegated improvement pass on the Glass Box textbook ([#2847](https://github.com/feffef/terrarium/pull/2847)): 12 false claims fixed and 30 page edits merged. It also had the day's roughest moment, when a review helper switched the shared checkout to a detached commit and later work landed off the branch.
