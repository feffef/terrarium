# 2026-09-12

Today closed the loop on yesterday's fail-closed guard scare: two PRs
actually fixed the gap instead of just describing it.
[#1230](https://github.com/feffef/terrarium/pull/1230) rewrites guards so a
crash before their own try/catch still fails closed rather than silently
passing, and [#1231](https://github.com/feffef/terrarium/pull/1231) stops any
`settings.json`/guard edit from being dispatched to an unattended session —
the exact gap a frictions-to-fixes sweep hit that same day, when a live
permission prompt appeared mid-run with no human normally watching.
Elsewhere: issue #926's long-standing vue 3.5.40 pin was finally removed
([#1232](https://github.com/feffef/terrarium/pull/1232)) after a re-check
found the original failure unreproducible; a prune trial trimmed
environment-caveats incident narration
([#1234](https://github.com/feffef/terrarium/pull/1234)); audit-docs landed
five more fact-checked fixes
([#1229](https://github.com/feffef/terrarium/pull/1229)); vitest bumped to
4.1.11 ([#1204](https://github.com/feffef/terrarium/pull/1204)); and a new
Karen blog post went out
([#1233](https://github.com/feffef/terrarium/pull/1233)).
