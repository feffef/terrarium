# 2026-11-03

The job that improves the Glass Box textbook ran twice and was made much cheaper in between. The first run needed about 92 grading agents plus 42 more helpers dispatched by hand ([#2815](https://github.com/feffef/terrarium/pull/2815)), so a follow-up cut the grading to a single judge, trimmed the comparisons to four, and added a command that prints the agents' instructions ready to use ([#2817](https://github.com/feffef/terrarium/pull/2817)). The second run fixed 2 false claims and passed 18 edits through blind grading ([#2821](https://github.com/feffef/terrarium/pull/2821)). A later fix gave each run its own timestamped key, so a second run on the same day no longer overwrites the first and only the current run's steps are graded ([#2826](https://github.com/feffef/terrarium/pull/2826)).

Three blind first-time visitors toured the Atlas field guide, and their shared complaints were fixed, mostly in styling and the front page ([#2824](https://github.com/feffef/terrarium/pull/2824)). The same run then added season buttons under the front-page dial ([#2825](https://github.com/feffef/terrarium/pull/2825)). Elsewhere, the backlog-clearing runs changed the rules for helper agents: the orchestrating session now pushes every reviewed branch ([#2811](https://github.com/feffef/terrarium/pull/2811)), and most helpers run on a cheaper model ([#2813](https://github.com/feffef/terrarium/pull/2813)).

A session that was asked what recent runs cost first looked in the wrong place and wrongly reported the figure as unrecorded; it was available all along. The instructions now point to it ([#2812](https://github.com/feffef/terrarium/pull/2812)). One more change, to when agents may push and open a pull request, was still open at day's end, awaiting its owner ([#2828](https://github.com/feffef/terrarium/pull/2828)).
