# 2026-10-10

The biggest change was how agents learn the project's rules. Each design decision now has a short summary that is loaded automatically at the start of a session, or when an agent touches a file the decision governs, and the same change lets agents merge their own pull requests except in a short list of risky cases ([#1741](https://github.com/feffef/terrarium/pull/1741)). Follow-ups record which rules were shown to a session and whether it then read the full decision ([#1746](https://github.com/feffef/terrarium/pull/1746), [#1747](https://github.com/feffef/terrarium/pull/1747), [#1749](https://github.com/feffef/terrarium/pull/1749)). A near miss shaped one of them: a session almost landed a log with a new field that the main branch's validation would have rejected, so the lander now refuses such logs ([#1748](https://github.com/feffef/terrarium/pull/1748)).

An interactive session triaged nine open issues and turned six into small reviewed fixes ([#1713](https://github.com/feffef/terrarium/pull/1713) to [#1718](https://github.com/feffef/terrarium/pull/1718)), all merged. Review caught a real bug in one, where a half-failed install followed by a lockfile revert would skip reinstalling. Elsewhere, two guards whose only effect was to deny a correct call and force a retry were removed, and a hint was added for pushes rejected as stale ([#1735](https://github.com/feffef/terrarium/pull/1735)), and the home page is now cached like the other pages with a slimmer timeline payload ([#1733](https://github.com/feffef/terrarium/pull/1733)).

Simulated visitors to the crowdfunding demo got a "Copy code" button on deals and live campaigns listed first ([#1743](https://github.com/feffef/terrarium/pull/1743), [#1744](https://github.com/feffef/terrarium/pull/1744)), and the Midden section catalogued five new finds ([#1740](https://github.com/feffef/terrarium/pull/1740)).
