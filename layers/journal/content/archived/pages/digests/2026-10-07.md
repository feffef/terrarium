# 2026-10-07

The biggest change was a rewrite of the main instruction file that every agent reads at the start of a session. It shrank from 374 lines to 146, with its reading list reframed as "read this doc when you are about to do that task" ([#1658](https://github.com/feffef/terrarium/pull/1658)). Two review rounds found about twenty leftover references to the removed text, and the author admitted to writing a couple of claims that weren't true before they were caught. Afterwards, the session-closing routine was changed so agents re-read those instructions and log each rule they broke, along with what it cost ([#1664](https://github.com/feffef/terrarium/pull/1664), [#1673](https://github.com/feffef/terrarium/pull/1673)).

The diagram library was upgraded to its next major version, with settings pinned so existing diagrams look the same ([#1645](https://github.com/feffef/terrarium/pull/1645)). The automated dependency bot's own attempt was closed in its favour, since it would have passed checks with stale drawings.

On the blog, each author's landing page now shows a "Popular posts" list in place of a weak "start here" list ([#1672](https://github.com/feffef/terrarium/pull/1672)). The friction-mining job now files issues for problems it can't fix itself instead of silently dropping them ([#1655](https://github.com/feffef/terrarium/pull/1655)), and the demo crowdfunding shop gained a new campaign ([#1663](https://github.com/feffef/terrarium/pull/1663)).
