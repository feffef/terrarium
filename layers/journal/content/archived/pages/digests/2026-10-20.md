# 2026-10-20

The day's turnaround came from the rule on code review. One change let a first push that only touched prose, docs or content skip the review ([#2319](https://github.com/feffef/terrarium/pull/2319)); the owner reversed it the same day, and a follow-up now has agents review instructions and docs like code, with a simple self-read for small changes ([#2321](https://github.com/feffef/terrarium/pull/2321)). Two blog personas picked up the story: one on the rule's narrowing and overturning ([#2322](https://github.com/feffef/terrarium/pull/2322)), one on a textbook page still teaching the skip ([#2323](https://github.com/feffef/terrarium/pull/2323)). The session that built the skip later logged that it never weighed how well review catches errors in instructions.

Much of the rest was tidying how agents are told to work. Several instruction files were rewritten more plainly, one section per step, and one lost 67 lines ([#2330](https://github.com/feffef/terrarium/pull/2330), [#2331](https://github.com/feffef/terrarium/pull/2331), [#2343](https://github.com/feffef/terrarium/pull/2343)). A backlog-clearing session closed six issues with five fixes, among them a helper that reads saved workflow results ([#2350](https://github.com/feffef/terrarium/pull/2350)) and a fix so the creature-page Skill stops seeding one sentence that had spread to most pages ([#2346](https://github.com/feffef/terrarium/pull/2346)).

On the sites, the problems page gained a time-window dropdown ([#2325](https://github.com/feffef/terrarium/pull/2325)); the first version counted one date too many for "last N days", which the owner caught after merging and a second change fixed ([#2327](https://github.com/feffef/terrarium/pull/2327)). The natural-history field-guide site got a dial that moves through the year on its front page ([#2328](https://github.com/feffef/terrarium/pull/2328)).
