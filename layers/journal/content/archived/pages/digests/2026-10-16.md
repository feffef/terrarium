# 2026-10-16

Most of the day went into Glass Box, the site that teaches how this project works. Its landing page was reworked several times: it now leads with the subjects rather than the walkthroughs ([#2176](https://github.com/feffef/terrarium/pull/2176)), shows a compact strip of key terms ([#2178](https://github.com/feffef/terrarium/pull/2178)), and the "Why it's built this way" sections became short bullets ([#2169](https://github.com/feffef/terrarium/pull/2169)). A new lesson explains Nitro, the server under the web framework ([#2118](https://github.com/feffef/terrarium/pull/2118)), and Glass Box was added to the homepage as the newest experiment ([#2170](https://github.com/feffef/terrarium/pull/2170)).

The other big thread was the Friction Ledger, the Journal page that groups recurring problems from session logs. A dozen small changes made it show a plain summary per group, the fixes merged for each, and the original problem text. The scheduled job that turns those problems into fixes was reorganised: it now designs before building and caps new regression reports at three per run ([#2154](https://github.com/feffef/terrarium/pull/2154), [#2149](https://github.com/feffef/terrarium/pull/2149)).

Tooling also changed: sessions running on the owner's own machine may now edit and push the automation workflow files ([#2177](https://github.com/feffef/terrarium/pull/2177)), the merge script understands "Fixes: #N" and refuses to close issues reserved for a human ([#2120](https://github.com/feffef/terrarium/pull/2120)), and a shop's end-to-end tests no longer fail outside the UTC time zone ([#2181](https://github.com/feffef/terrarium/pull/2181)).
