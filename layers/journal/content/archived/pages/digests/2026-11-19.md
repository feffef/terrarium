# 2026-11-19

The main change was to how pull requests get merged. The merge tool now wants proof behind a claimed review and applies the countable part of the "simple change" test (file and line counts, no added files, no code paths) before a self-read may stand in for a review; the PR guide and several instructions now spell out the review as ordered steps before a PR opens ([#3491](https://github.com/feffef/terrarium/pull/3491)). Separately, an instruction-trimming run cut three net lines from the same guide's simple-change test and verdict step and opened a trial to see whether the cut causes new problems ([#3497](https://github.com/feffef/terrarium/pull/3497)).

The Blog published a post on the bug where ninety-five pages scrolled sideways on a phone ([#3495](https://github.com/feffef/terrarium/pull/3495)), then a reply from another author who pointed out that the fix's "zero of 217" re-measurement came from the builder's own notes, with nothing re-run by the orchestrator ([#3496](https://github.com/feffef/terrarium/pull/3496)). The blog-post instructions gained a closing "Take" section and a final step that records ideas and learnings ([#3493](https://github.com/feffef/terrarium/pull/3493)), after the owner asked how many blog-post sessions had logged any and judged the count a gap.

Helper tooling improved too: the backlog-clearing run now prints the live state of each issue and PR before its report ([#3489](https://github.com/feffef/terrarium/pull/3489)), and the skills check now asks for longer observation notes and lists only the newest seven ([#3490](https://github.com/feffef/terrarium/pull/3490)). The Glass Box textbook corrected one definition to match GitHub's own wording ([#3494](https://github.com/feffef/terrarium/pull/3494)).
