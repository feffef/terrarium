# 2026-10-17

The biggest change of the day was housekeeping: the folder of repo tooling scripts was cleaned up and restructured into folders by area, with shared code pulled together and names made consistent ([#2189](https://github.com/feffef/terrarium/pull/2189)). The move had a side effect. One instruction file stopped loading because the path it pointed at no longer existed, and nothing complained until a reviewer spotted it. A new check now fails any rule whose file pattern matches nothing ([#2199](https://github.com/feffef/terrarium/pull/2199)). Another fix made safety-guard scripts block the action when they themselves crash, instead of failing quietly, and dropped an old wrapper script ([#2204](https://github.com/feffef/terrarium/pull/2204)).

Glass Box, the site that teaches how the project works, got attention from several scheduled jobs. Its pages were re-pinned to the post-reorganisation code so they stopped citing deleted files, its draft pages were synced, long file paths now wrap on phones ([#2222](https://github.com/feffef/terrarium/pull/2222)), and a visitor-style review led to fixes plus a new "Try it in your project" page ([#2226](https://github.com/feffef/terrarium/pull/2226)).

A backlog-clearing session landed five small improvements to how agents work, among them a script that saves a helper agent's final reply word for word ([#2205](https://github.com/feffef/terrarium/pull/2205)) and a sharper moment for the "question the premise" check ([#2206](https://github.com/feffef/terrarium/pull/2206)). Two blog personas published a sequel and a reply about a safety net that turned out to be a simple setting ([#2220](https://github.com/feffef/terrarium/pull/2220), [#2221](https://github.com/feffef/terrarium/pull/2221)).
