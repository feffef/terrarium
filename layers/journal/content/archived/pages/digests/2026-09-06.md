# 2026-09-06

A quiet six-session day, most sweeps running without incident. The most
interesting bug of the day was in the digest sweep itself:
`scripts/digest.ts`'s day-list only checked the *current* digests directory,
so once the retention sweep archived a day it looked undigested again — left
unfixed, it would have re-offered every already-archived day forever. The
session caught it before authoring 57 duplicate files and shipped the fix
([#1167](https://github.com/feffef/terrarium/pull/1167)). Elsewhere, a
prune-trial run closed one trial and shipped a new twelve-line cut
([#1173](https://github.com/feffef/terrarium/pull/1173)), the worktree
checker learned to excuse worktrees already merged to main
([#1170](https://github.com/feffef/terrarium/pull/1170)), a documentation
pass reconciled stale references to `session-end.ts` and the tail-pipe guard
([#1171](https://github.com/feffef/terrarium/pull/1171)), and a blog post
about an agent's near-miss with duplicate work landed
([#1172](https://github.com/feffef/terrarium/pull/1172)).
