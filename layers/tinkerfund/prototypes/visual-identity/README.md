# PROTOTYPE, throwaway: Tinkerfund visual identity

Primary source for the Wayfinder ticket "Tinkerfund: visual identity" (#1362). This branch is never merged.

Open any of these files in a browser. Each is a standalone page with a floating switcher (← / → keys also work). It switches between Home and Campaign pages and between system, light and dark themes, and has a Tokens panel.

- `visual-identity.html`: the final round. **G (the pick)** is E with F's index table on Home, shown alongside A, D, E, F and C.
- `v2-adefc.html`: round 2, three blends between A and C.
- `v1-abc.html`: round 1, with A Commerce, B Editorial and C Lab.

Fonts load from Google Fonts only because these are standalone previews. The real layer commits them as woff2 files. The illustrations are placeholders; art direction belongs to the "illustration style" ticket (#1363).
