# PROTOTYPE, throwaway: Tinkerfund illustration style

Primary source for the Wayfinder ticket "Tinkerfund: illustration style" (#1363). This branch is never merged.

Open `illustration-style.html` in a browser. The floating bar (or ← / →) switches between three art directions for TF-0006 Rain-Aware Umbrella. Each has FIG. 1 (hero) and FIG. 2 (gallery shot):

- **P**: patent drawing (monochrome ink line, hatching, numbered callouts)
- **R**: risograph, two inks (accent + link, overprinted, halftone)
- **I**: flat isometric (filled token planes, no outlines)

Each is shown inside the chosen "Instrument" identity (#1362, variant G): the Campaign gallery and readout, a Home index row, a card, and both themes side by side. All art is inline SVG coloured only by theme tokens. The note panel shows each figure's raw and gzip size.
