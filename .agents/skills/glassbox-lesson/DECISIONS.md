# Glass Box decisions

Closed rulings on Glass Box pages, from the owner or settled in a review. A
finding that contradicts a line here is dropped. Add a line when the owner
overrules a run or settles a point reviewers disagree on: one line each, in the
order added, with where it was made.

- *Author trust* keeps its title: clearer than the field name, and its lede names `author_association` (review, #2500).
- Field names replace project jargon in titles: *Blocking hooks*, not guards that fail closed; *Commit and PR attribution*, not provenance (owner, #2598).
- A missing `publishedAt` is not a deficit; EVERY-PAGE's Pin says when a page gets one (review, #2500).
- *Continuous deployment*'s Full reference stays Wikipedia: a practice has no official docs (review, #2500).
