# ADR-0022: The triage sweep may mark Trusted issues ready to build

When a Trusted user starts the `auto-triage` sweep, by hand or through a
Routine or `/loop`, that run may label a Trusted-authored issue
`ready-for-agent` once the repo settles a concrete design; that label stays
the approval after the run ends. Send Public-authored
issues, anything a Public comment asks for, judgment calls and real design
doubt to `ready-for-human`. Close only duplicates and already-done work. The
sweep never builds; the resulting PRs merge like any other (ADR-0004).

Read `docs/adr/0022-autonomous-triage-sweep.md` (~900 tokens) to change it or review work it governs, or to see what counts as a judgment call or real design doubt.
