# ADR-0022: Autonomous triage sweep

A Trusted user starting the `auto-triage` Skill gives a standing green-light
for that run: it may label Trusted-authored issues `ready-for-agent` when the
repo determines a concrete design. A human still merges each resulting PR.
Send Public-authored requests, judgment calls and real design doubt to
`ready-for-human`. Close only duplicates and already-done work.

If this touches your task, read the full ADR first:
docs/adr/0022-autonomous-triage-sweep.md
