# ADR-0021: A Platform glossary plus one context per Tenant

Put a term in root `CONTEXT.md` only if every agent needs it whatever the
task; keep that file a glossary, with the Tenant list and retired terms. Put a
Tenant's own terms, why it exists and its product decisions in
`layers/<tenant>/CONTEXT.md`. Define each term once. Record only decisions
about the Platform and how agents work on it in an ADR, never a demo Tenant's
product choices. A new Tenant
adds its `CONTEXT.md`, a line in the root list and an entry in
`CONTEXT-MAP.md`.

If this rule seems relevant to your task, you must read the full ADR first (about 900 tokens):
docs/adr/0021-multi-context-domain-docs.md
