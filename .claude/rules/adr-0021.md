# ADR-0021: A Platform glossary plus one glossary per Tenant

Put a term in root `GLOSSARY.md` only if every agent needs it whatever the
task; keep that file to definitions and retired terms, and `GLOSSARY-MAP.md`
to the list of glossaries (one per Tenant) and how they relate. Put
instructions and rationale where they are used, not in either; an entry may
still say which word to use. Put a
Tenant's own terms, why it exists and its product decisions in
`layers/<tenant>/GLOSSARY.md`. Define each term once. Record only decisions
about the Platform and how agents work on it in an ADR, never a demo Tenant's
product choices. A new Tenant
adds its `GLOSSARY.md` and an entry in `GLOSSARY-MAP.md`.

Read `docs/adr/0021-multi-context-domain-docs.md` (~900 tokens) to change it or review work it governs.
