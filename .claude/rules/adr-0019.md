# ADR-0019: A failed content load shows a reload dialog; a failed download reloads

`@nuxt/content` runs unpatched. A page or component that queries Content in
the browser mounts `ContentLoadErrorDialog` with its `useAsyncData` status and
error; the dialog's fix is a full page reload. Only a failed download of a code
chunk or of the Content database reloads by itself, once per path; a second
failure, a corrupt database and a query error keep the dialog. Add no in-page
retry.

If this touches your task, read the full ADR first (it's only 71 lines):
docs/adr/0019-patched-nuxt-content-client-db-loading.md
