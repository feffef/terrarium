# ADR-0019: Recovering from failed content loads

`@nuxt/content` runs unpatched. When a page's client-side content load fails,
it shows `ContentLoadErrorDialog` with a Reload button, since only a fresh
page recovers the client DB. A failed chunk import is the one case that
reloads itself, once per path (`app/composables/contentLoadRecovery.ts`). Most
navigation skips the client DB (ADR-0028).

If this touches your task, read the full ADR first:
docs/adr/0019-patched-nuxt-content-client-db-loading.md
