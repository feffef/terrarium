# ADR-0024: Mermaid diagrams are pre-rendered to committed SVG

Mermaid diagrams are rendered at authoring time to SVGs committed in
`app/assets/mermaid/`; the app ships no mermaid JS. After editing a diagram,
run `pnpm render:mermaid` (needs Chromium) and commit every SVG change;
`verify:mermaid` in the gate checks this. Colours stay live via
`var(--diagram-*)`; fonts and layout are baked.

If this touches your task, read the full ADR first:
docs/adr/0024-build-time-mermaid-prerender.md
