# ADR-0029: Instructions load with the files they govern

An instruction a glob can match to its files lives in a path-scoped rule in
`.claude/rules/`; one that matters on an action stays in `CLAUDE.md`. Every ADR
has a summary rule, stamped with its ADR's hash. A non-ADR rule always has
`paths`: a short instruction lives in it alone, a long one stays in its doc and
the rule points there. Rules load on Read, Edit, Write and a lone single-file
Bash read, not on piped or chained commands.

If this touches your task, read the full ADR first:
docs/adr/0029-instructions-load-with-the-files-they-govern.md
