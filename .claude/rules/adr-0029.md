# ADR-0029: Instructions load with the files they govern

Put an instruction about certain files in a rule in `.claude/rules/` whose
`paths` match them. Keep instructions for every session, or for an action such
as a commit or a PR, in `CLAUDE.md`. Each ADR summary rule says when to read its
ADR in full, gives its key parts as instructions and decides nothing the ADR
doesn't; only the human-merge rule holds a fact itself, its `paths` being the
Human-only list. Give every other rule `paths`, a few lines, and a pointer to
its doc if the instruction is long. A rule can't order a step before the read
that loads it. Make every `docs/agents/` doc reachable from `CLAUDE.md` or a
rule.

Read `docs/adr/0029-instructions-load-with-the-files-they-govern.md` (~900 tokens) to change it or review work it governs, or to see whether an instruction belongs in a rule or CLAUDE.md.
