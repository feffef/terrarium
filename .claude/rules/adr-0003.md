# ADR-0003: Agent operating model and governance

Every change lands as a gated PR from a feature branch. Open the PR yourself
and follow it until it merges. A human merges it by default; a chartered job
in this ADR's ledger table merges its own PR on a green gate, within its row's
scope (mechanics: `docs/agents/pr-workflow.md`). Build net-new work only after
a Trusted human approves it (ADR-0020).

If this touches your task, read the full ADR first:
docs/adr/0003-agent-operating-model-and-governance.md
