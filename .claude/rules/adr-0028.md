# ADR-0028: Navigation reads server-rendered payloads

In-app navigation reads the target route's server-rendered `_payload.json`
instead of querying Content in the browser, and only cached routes have one:
`routeRules` in `nuxt.config.ts` cache `/` and `/t/**` for 60 s. A cached page
renders once for every visitor, so a page that reads a request header or
cookie needs `varies`, as Tinkerfund's do. Server-computed "now" can be about
two minutes old.
