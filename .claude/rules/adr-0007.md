# ADR-0007: Derived files are built, not committed

Derive at build time anything the build can make, such as what the manifests
determine; commit no generated copy. Commit a derived file only when the build
cannot make it, keep its derivation deterministic, and add a gate check that
fails when it drifts from its source.

Read `docs/adr/0007-derived-files-built-not-committed.md` (~600 tokens) before you change this decision, or when you'd commit a generated file.
