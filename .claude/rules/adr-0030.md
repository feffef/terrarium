# ADR-0030: How we write ADRs

An ADR states one decision as it stands today, with its scope and limits, why,
and the rejected alternatives. To change it, rewrite it in place: no
amendments, dates or history notes, since git holds the history. The ADR is the
source; its summary rule never decides anything the ADR doesn't. A full rewrite
follows ADR-0030's template.

If this touches your task, read the full ADR first:
docs/adr/0030-how-we-write-adrs.md
