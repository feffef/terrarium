# ADR-0030: ADRs state the current decision

An ADR states one decision as it stands today, with its scope and limits, why,
and the rejected alternatives. To change it, rewrite it in place: no
amendments, dates or history notes, since git holds the history. Its summary
rule adds nothing the ADR doesn't say; procedures go in docs or Skills. A full
rewrite follows ADR-0030's template.

If this touches your task, read the full ADR first:
docs/adr/0030-adrs-state-the-current-decision.md
