# ADR-0018: Tenant layers, and how to edit an ADR

Tenants live as Nuxt layers in `layers/<tenant>/`. Nuxt auto-extends every
`layers/*`, so a new Tenant needs no `nuxt.config.ts` edit; only
`../layers/*/tenant.config.*` needs the manual tsconfig glob. To fix a wrong
detail in an ADR, edit it in place. To change a decision, append a dated
amendment and keep the original Decision and Consequences (prune trials:
ADR-0027).

If this touches your task, read the full ADR first:
docs/adr/0018-tenant-layers-under-layers-directory.md
