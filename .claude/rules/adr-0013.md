# ADR-0013: content.config.ts builds collections from the manifests

`content.config.ts` is an ordinary module you can edit by hand. At config time
it builds every keyed Collection from `expand(loadManifests())` in
`shared/expand.ts`, which loads each `layers/*/tenant.config.ts` through jiti.
A manifest edit applies on the next prepare, build or dev start, with no
regenerate step and no committed generated file.
