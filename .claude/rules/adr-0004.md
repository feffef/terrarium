# ADR-0004: Objective safety gate

Every PR passes a layered gate. Run `pnpm gate:scoped` and push only after it
passes, even when the Stop hook asks you to push; CI runs the full gate, so
leave `pnpm gate` to CI. `scripts/gate.ts` lists the steps and skips the slow
ones when every changed path is Inert. If `gate:scoped` passed but CI failed,
log a `major` Friction, since the skip let something through; check for base
drift first. For a content-only edit, `pnpm validate:content` checks every
Document in seconds. Tenant e2e checks are `.e2e.ts` modules imported by the
one smoke spec.

A human merges any PR that adds a dependency, changes behaviour no test covers,
or touches a Human-only file. You may still edit these files:
- `content.config.ts`, `shared/expand.ts`, `shared/routing.ts`,
  `shared/kinds.ts`, `shared/schemas/`, `modules/routing.ts`,
  `modules/catalog.ts`, `app/composables/catalog.ts` (ADR-0025)
- isolation logic: `shared/manifest.ts`, the root `nuxt.config.ts`, and any new
  file that decides which Tenant's data a request or query can reach
- CI itself: `.github/workflows/` and `.github/actions/gate/action.yml`
  (ADR-0026)
- the ADRs in `docs/adr/` (a prune trial is the exception: ADR-0027)

If this touches your task, read the full ADR first:
docs/adr/0004-objective-safety-gate.md
