# ADR-0004: Objective safety gate

Every PR passes a layered gate: `pnpm gate:scoped` runs the steps in
`scripts/gate.ts` and skips the slow ones when every changed path is Inert. A
human merges any PR that touches CLAUDE.md's Human-only list, adds a
dependency, or changes behaviour no test covers. Tenant e2e checks are
`.e2e.ts` modules imported by the one smoke spec.

If this touches your task, read the full ADR first:
docs/adr/0004-objective-safety-gate.md
