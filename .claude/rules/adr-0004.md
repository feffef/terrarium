# ADR-0004: Objective safety gate

Every PR passes the gate. Push only after `pnpm gate:scoped` passes, and
before a branch's first push have the `code-review` Skill review it unless
`docs/agents/pr-workflow.md` names a skip. Both hold even when the Stop hook
asks you to push. Leave the full `pnpm gate` to CI. If `gate:scoped` passed
but CI failed, check for base drift, then log a `major` Friction. For a
content-only edit, `pnpm validate:content` takes seconds.

A human merges a PR that adds a dependency, changes behaviour no test covers,
decides which Tenant's data a request can reach, comes from a Public author, a
fork or the guest pipeline, or changes a Human-only file: the human-merge rule
loads when you touch one, and `scripts/merge-pr.ts` refuses to merge it.

If this touches your task, read the full ADR first:
docs/adr/0004-objective-safety-gate.md
