# ADR-0025: Reads across Tenants go through opted-in collection kinds

A Collection is readable outside its Tenant only when its manifest names a
kind from `shared/kinds.ts`; the kind's contract is a minimum, merged with the
Collection's own fields. Read across Tenants only through `queryAcrossTenants`
or `queryPages` (`app/composables/catalog.ts`), never through another Tenant's
manifest or collection keys. Put a view whose whole job is to look across
Tenants in the Commons as a new Space, with its own logic in its layer. Any
Tenant layer may call the read functions, and a view that does is an ordinary
change; which catalog files wait for a human merge is ADR-0004's list. Link
each result to the item's own URL.

If this touches your task, read the full ADR first:
docs/adr/0025-cross-tenant-catalog-and-collection-kinds.md
