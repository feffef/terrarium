# ADR-0001: One container, content baked at build time

The Platform is one Nuxt app, one repo and one container. Each Tenant ×
Space × Collection is its own collection, built from committed files into one
SQLite DB at build time. Requests choose among baked content, so you add a
Tenant, Space or data by editing files. Every image holds every Space: Spaces
are separated, not air-gapped.
