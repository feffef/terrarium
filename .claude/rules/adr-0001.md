# ADR-0001: One app serves every Tenant from content built ahead of time

The Platform is one Nuxt app in one repo, shipped as one container. The build
turns committed files into one SQLite database, with its own table for each
Tenant × Space × Collection; nothing is created while the site runs. To add a
Tenant, Space or content, edit files and rebuild. A request fetches no outside
data, and the site stores nothing visitors write: a feature that needs either
needs a new decision first. Spaces are kept apart by their tables, not by
separate builds, so every container image ships every Space's content.

Read `docs/adr/0001-single-container-baked-multitenancy.md` (~700 tokens) before you change this decision, or when a feature needs outside data, visitor data or a Space kept out of an image.
