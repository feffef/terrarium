# ADR-0026: CI's gate steps live in an action that agents can push

Change the gate's CI steps in `.github/actions/gate/action.yml`; agents can
push it. A cloud session cannot push `.github/workflows/gate.yml`: from there,
a change to its triggers or permissions goes to a human through
`docs/proposals/`. A local session can push it. When you
add, drop or reorder a gate step, change `package.json`'s `gate`,
`scripts/gate/gate.ts` and the action together; `tests/unit/gate-parity.spec.ts`
fails until they agree. A human merges a change to the action or the workflow
file (ADR-0004).

Read `docs/adr/0026-gate-workflow-thin-shell.md` (~900 tokens) to change it or review work it governs, or to see what must stay in the workflow file.
