# ADR-0026: The Gate workflow is a thin shell

The Gate's steps live in the composite action `.github/actions/gate/action.yml`:
agents edit and push it, and a human merges it. `.github/workflows/gate.yml`
is a thin shell for triggers and permissions; propose changes to it in
`docs/proposals/`. Keep `package.json`'s `gate`, `scripts/gate.ts` and the
composite in sync; `tests/unit/gate-parity.spec.ts` checks it.
