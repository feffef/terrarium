# ADR-0011: Self-updating deploy container

The live site runs a thin container: `deploy/Dockerfile` holds only tools, and
`deploy/entrypoint.sh` clones `main`, builds it and polls for new commits. It
swaps to a new build only when install and build succeed, and keeps serving
the last good one otherwise. So a merge to `main` runs code on the server, and
this is the one place a build runs at runtime (ADR-0001). A change to
`deploy/` itself reaches the server only after the operator rebuilds the image.
