# ADR-0005: Skills are Platform code, committed with the repo

Keep each Skill in `.agents/skills/<name>/` with a link in `.claude/skills/`,
and change it through a gated PR like any code. A Skill that changes the
Platform works on any Tenant through its manifest; give one Tenant its own
Skill only for a repeated workflow unique to it. Pack Skills stay as installed
(ADR-0015); a doc copied from a pack template is ours and is never re-synced.
A workflow script is its Skill's code: a real file in
`.claude/workflows/<name>.js`, named by the Skill that runs it. A schedule
lives in a Routine, not in the Skill.

If this touches your task, read the full ADR first:
docs/adr/0005-skill-model.md
