# ADR-0005: Skills are Platform code

Skills are Platform code. Keep each in `.agents/skills/<name>/` with a symlink
in `.claude/skills/`, and change it through a gated PR. Write
Platform-operation Skills to work on any Tenant through its manifest; give one
Tenant its own Skill only for a repeated workflow unique to it. Pack Skills
listed in `skills-lock.json` stay as installed (ADR-0015). A Claude Code
workflow script is its Skill's code: a real file in
`.claude/workflows/<name>.js`, named by the Skill that runs it.
