# ADR-0006: Routing by path prefix

A Space's pages live at `/t/<tenant>/<space>/<slug>`. Only a Space's `pages`
Collection gets routes; its other Collections are data that pages read. Every
Space page, the Platform catch-all or a Tenant layer page, resolves through
`useSpace` and `resolveSpaceRoute` (`shared/routing.ts`), which reads one
Space's keys from `#routing` and returns a 404 for an unknown one.
