# ADR-0002: One manifest per Tenant

Each Tenant declares its Spaces, Collections, schemas and routing in one
manifest, `layers/<tenant>/tenant.config.ts`, whose `name` matches its folder.
Edit only the manifest: `shared/expand.ts` expands all manifests into the keyed
collections and routes at build time (ADR-0013, ADR-0014). A new Tenant is a
new layer folder with a manifest; run `pnpm install` afterwards.
