# ADR-0008: The Journal documents the Platform

The `journal` Tenant (`layers/journal/`) is how the Platform documents itself;
it is Platform infrastructure, not a demo Tenant. It holds Inventories, which
are derived and refreshed in place (the Skill Inventory), session logs, which
agents write honestly and add to over time, and Digests (ADR-0010). Session
logs are ground truth and cannot be rebuilt from the repo.
