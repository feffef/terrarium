# ADR-0009: Session logs go straight to main

Invoke `close-session` when you open a PR, and again when the task is done or
blocked on someone else; re-invoking it is safe. It writes your session log,
and the session hooks run `scripts/log-session.ts --land`, which commits that
one file straight to `main` in `layers/journal/content/current/sessions/`, with
no PR. Record every Friction honestly: the self-improvement Skills learn from
them. Keep the log out of your branch, and treat landed logs as fixed.

If this touches your task, read the full ADR first:
docs/adr/0009-session-logs-commit-directly-to-main.md
