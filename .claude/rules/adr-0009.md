# ADR-0009: Session logs go straight to main

Your session log goes straight to `main` as one file in
`layers/journal/content/current/sessions/`, with no PR. Invoke `close-session`
to write it; the session hooks run `scripts/log-session.ts --land`, which
commits only that file. Keep the log out of your branch, and treat landed logs
as fixed.

If this touches your task, read the full ADR first:
docs/adr/0009-session-logs-commit-directly-to-main.md
