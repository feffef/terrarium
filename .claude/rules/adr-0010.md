# ADR-0010: Digests

A Digest is a derived daily catch-up page that stays fixed once written: one
file per closed UTC day with activity, at
`layers/journal/content/current/pages/digests/<date>.md` in the Journal's
`pages` collection. The `digest` Skill writes it from `scripts/digest.ts` and
lands it as a gated PR (merge scope: ADR-0003). The dashboard lists Digests
live.
