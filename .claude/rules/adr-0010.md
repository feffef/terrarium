# ADR-0010: A Digest is a daily Journal page, written once and landed by PR

A Digest is an ordinary page in the Journal's `pages` collection under
`digests/<date>`, one per finished UTC day with activity. The `digest` Skill
writes it and lands it by an ordinary gated PR, never straight to `main`. A run
never rewrites an existing Digest; fix a wrong fact by an ordinary PR. Moving
one to `archived` is fine. Keep Digest lists out of the index: the home page
reads them live.

If this touches your task, read the full ADR first:
docs/adr/0010-digests-derived-append-only-journal-pages.md
