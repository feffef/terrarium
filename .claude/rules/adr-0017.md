# ADR-0017: Every agent write names the session that made it

Agents act on GitHub as the owner, so every agent write to GitHub, git or any
other outside system names this session. Start each GitHub body (issue, PR,
comment, review) with `🤖 [Claude](https://claude.ai/code/session_<id>)` as
line one, using this session's id; replace a header copied from another
session. The header alone marks the post as an agent's.
`scripts/github-provenance-guard.ts` blocks an MCP-tool body without it; a
`gh api` write goes unchecked, so write through MCP.
`.githooks/commit-msg` adds the commit trailer; check that it landed. To tell
an agent's post from a human's, use `hasAuthorshipMarker`, never the login.
