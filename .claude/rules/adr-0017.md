# ADR-0017: Every agent write names the session that made it

Agents act on GitHub as the owner, so every agent write to GitHub, git or any
other outside system names this session. Start each GitHub body (issue, PR,
comment, review) with `🤖 [Claude](https://claude.ai/code/session_<id>)` as
line one, using this session's id (a local session uses its raw UUID in
place of `session_<id>`); replace a header copied from another session. The
header alone marks the post as an agent's.
`scripts/hooks/github-provenance-guard.ts` blocks a body without it, sent through
MCP or a shell `gh api` or `curl` command; write through MCP.
`.githooks/commit-msg` adds the commit trailer; check that it landed. To tell
an agent's post from a human's, use `hasAuthorshipMarker`, never the login.

Read `docs/adr/0017-provenance-footer-on-agent-authored-content.md` (~1100 tokens) to change it or review work it governs, or to see which old marks still count and which writes the guard can't see.
