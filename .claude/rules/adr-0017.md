# ADR-0017: Provenance on every agent write

GitHub shows agent actions as the owner's, so every agent write to GitHub or
any other outside system names its session. Start each GitHub body (issue,
PR, comment, review) with `🤖 [Claude](https://claude.ai/code/session_<id>)`
as line one, using this session's id. `scripts/github-provenance-guard.ts`
checks it, and `.githooks/commit-msg` adds the commit trailer.
