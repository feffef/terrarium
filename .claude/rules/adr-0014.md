# ADR-0014: The #routing build-time module

`modules/routing.ts` builds the routing map from `expand(loadManifests())` at
build time, writes it to `.nuxt/routing.mjs` and exposes it as `#routing`.
After adding a layer or rebasing, run `pnpm install` (it runs `nuxt prepare`)
to refresh `.nuxt/`. Mirror every `#` alias in `vitest.config.ts` and
`tsconfig.node.json`. A brand-new layer folder needs a dev-server restart.
